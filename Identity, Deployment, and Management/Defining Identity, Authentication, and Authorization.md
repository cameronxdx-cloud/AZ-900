## Identity
- Who or what a person or object claims to be. "This is who/what I am"
## Authentication 
- The process of validating an identity. "This is the proof of who/what I am"
## Authorization
- The process of validating what an identity can do. "This is where I can go and what I can do"

### Identity Examples
- Physical World:
	- Passport 
	- Drivers license 
- Digital World:
	- Azure Active Directory object
	- Software license 
	- Email ID
### Authentication Examples
- Physical World:
	- House Key 
	- Certificate of authenticity 
	- Safety deposit box password 
- Digital World:
	- SSH Key
	- SSL Certificate 
	- Email account password
### Authorization Examples
- Physical World:
	- Event ticket 
	- Gate-specific key code 
	- Key card 
- Digital World:
	- Application Secret 
	- Shared access signature (SAS) token
	- Key card 

# Identity, Authentication, and Authorization Management 
Azure 
- All the resources and services available in Microsoft's cloud offering 
Azure Active Directory 
- Service for managing identity, authentication, and authorization that can be applied to those resources to those in Azure. 
### Summary 
- Identity: The unique identifier for any digital object 
- Authentication: proves identity
- Authorization: scopes identity 
	- All needed in order to effectively administer any digital environment. 
	- Microsoft Entra ID service provides all three
