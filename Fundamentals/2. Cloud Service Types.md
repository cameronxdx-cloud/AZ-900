### Infrastructures as a Service (IaaS):

##### What is IaaS?

- IaaS (Infrastructure as a Service) — In this offering, the cloud providers offer barebone hardware in managed data center such as virtual machine or file storage. The cloud providers will take care of the physical infrastructure e.g. data center security or hardware repair, while the cloud users need to take care of server maintenance. For example, Azure VM allows the users to spin up new virtual machines in any size.
- Cloud Vendor is responsible for your physical datacenter
- Networking/Cabling
- Physical Servers
- Pay-as-you-go managed IT Infrastructure
- Provisioned and managed over the internet
- Fundamental building block of all other cloud services

## Platform as a Service(PaaS):

- PaaS (Platform as a Service) — The cloud providers will take care of the servers. The cloud users only need to bring in application code or data. For example, Azure SQL Database is fully managed service by Azure that the users do not need to / cannot access anything beyond their data.
- PaaS Terminology: "Fully Managed"
- Managed development/Deployment Services
- Develop applications/solutions without managing infrastructure
- Cloud Vendor focuses on infrastructure - you focus on developing solutions
- e.g. software development, managed DB/Storage, Analytics
- Managed services for developing solutions 
  - Dont need to manage infrastructure
  - Instead, focusing on solutions/code/application
- Specialized services for different use cases
- Serverless = Extreme PaaS 
  - Run code with no infrastructure management
- Trade less flexibility/control for less management

#### Examples of PaaS:

- Databases - set up software, licenses
- Software Development
- Web app Deployment (app service - azure)
- Storage Services
- Business Analytics
- Security Solutions

### Software as a Service (SaaS):

- SaaS (Software as a Service) — The cloud providers will take care of both servers and code. The cloud users only need to configure the software to suit their needs. For example, Office 365 allows the users to use Microsoft Office software suite.
- Applications hosted and accessed over the internet
- Subscription pricing model
- E.g. O365, Zoom, Slack, Saleforce

## Defense in Depth

- protect our information or data unauthorized data access
- Layered defense
- If one layer is breached, other layers can still stop attacks
- 7 Layers:
- Physical Security 
  - First line of defense
  - Building/hardware access
- Identity and access: 
  - Securing identies
  - Grant account access to only what's needed user by user bases
- Perimeter: 
  - Protect against network-based attacks
  - Firewalls/DDoS protection
- Network: 
  - Secure connectivity between resources
  - Limit communications
  - Deny traffic
  - Securely connect to on-prem network
- Compute: 
  - Secure VMs
  - Endpoint protection/OS Patching
- Application: 
  - Resolve application vulnerabilities
  - Secure secrets
  - Design for security
- Data 
  - Primary target!
  - Databases, disks, SaaS applications
  - Control access
