# Benefits of Cloud Computing 

## High Availability: 

The major cloud providers (Azure, AWS, GCP) have multiple data centers spread around throughout the world. Data and code stored in the cloud are copied to more than one data center. If anything happens to one data center, the data can be recovered from another data center for redundancy. 

- Clusters ensure improved high availability - Paired with load balancers

## Scalability: 

- The application running in the cloud can expand its size when there are more users in the system.
  - Increase resources to meet demand 
  - Scale resources up and down to meet demand 
- Horizontal: Scale out 
  - Add additional VM(s) copies 
  - Load balancer distributes traffic across VMs
  - Automatic, no downtime 
  - Typical Cloud model 
- Vertical: Scale up 
  - Increase compute resource on existing server/VM
  - Add CPU/RAM/disk space 
  - (Usually) manual, requires downtime/reboot 

## Elasticity:

- The application running in the cloud can shrink its size when there are fewer users in the system. The users can also set automatic shutdown during the non-business hours to save money.

## Reliability:

- Ability to recover from failures and disasters and continue to function with minimum downtime
  - How does the cloud help?
    - Reliability describes the resilience of cloud computing where high availability doesn't guarantee zero downtime.
- When something causes an Azure service or resource to fail, its dealt with by Azure automatically. This is used by 2 strategies:
  - 1st no single point of failure overlap with high availability
  - The cloud by virtue of its decentralized design naturally supports a reliable and resilient infrastructure. This means even if one computer or VM goes down, other copies of that resources picks up that load right where it left off 
  - Applies to the cloud vendors and your resources 
  - Deploy to multiple locations - Global scale
  - Protect against regional failure/disaster 
  - Bonus: Always be close to your customer, wherever they are!
